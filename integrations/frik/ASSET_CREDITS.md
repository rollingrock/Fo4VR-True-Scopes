# FRIK menu assets

The True Scopes launcher uses custom artwork and a mesh generated with the
[F4VR-CommonFramework VRUI atlas tool](https://github.com/ArthurHub/F4VR-CommonFramework/blob/3f0bbc8c45c1193b16ca1c09b9f8ba2a97b95890/nif-tools/vrui_atlas.py).
The editable texture is stored as an uncompressed RGBA DDS file. The
calibration panel draws its controls at runtime.
